Steel Emporium is a full-stack web application developed using Spring Boot for backend and HTML, CSS, and JavaScript for frontend.
It allows users to manage steel products, customers, and orders efficiently.

🛠️ Technologies Used
Java
Spring Boot
HTML, CSS, JavaScript
MySQL
✨ Features
Manage steel products
Customer management
Order management system
User-friendly interface
▶️ How to Run
Clone the repository
Open in VS Code or IntelliJ

Run the application using:

mvn spring-boot

Open browser:
http://localhost:8082
